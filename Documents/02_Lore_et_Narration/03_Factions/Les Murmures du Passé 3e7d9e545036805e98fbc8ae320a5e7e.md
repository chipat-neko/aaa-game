# Les Murmures du Passé

Idéologie: Éco-terrorisme magique. Sceller les ruines antiques pour empêcher l'apocalypse. Sabotage du Conclave.
Importance: Mineure
Mécanique de Déchéance (AAA): Si le joueur ouvre toutes les ruines : La faction s'éteint dans un baroud d'honneur suicidaire, libérant un boss secret sur la carte.
Zone d'influence: Zones de fouilles archéologiques, frontières sauvages.
